## MCQ Quiz

A console-based Multiple Choice Quiz application developed using Java. Users can answer questions, check their answers, and view their final score.

## Features

- 15 multiple-choice questions.
- Four options for each question.
- Automatic answer validation.
- Displays correct and incorrect answers.
- Calculates final score and percentage.
- Shows performance feedback.

## Technologies Used

- Java
- Arrays
- Object-Oriented Programming (OOP)
- Scanner

## How to Run

javac MCQQuiz.java

java MCQQuiz
